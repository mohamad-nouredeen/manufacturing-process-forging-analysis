# 3D QForm Simulation

This folder contains the 3D QForm simulation used to evaluate the final forging process and its thermal behavior.

The analysis includes:

- 3D material flow during forging
- Workpiece temperature
- Tool temperature
- Lubricant influence on thermal behavior
- Final process evaluation

## Thermal Analysis

The initial simulation showed that the minimum workpiece temperature dropped below the desired forging range.

The lubricant was then changed from graphite + water to glass, and the process was simulated again.

The updated simulation showed improved workpiece temperature behavior and reduced tool heating.

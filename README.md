# Manufacturing Process – Forging Analysis

Design, simulation, and optimization of a **C45 steel hot-forging process**, including CAD modeling, billet and die dimensioning, flash design, and 2D/3D QForm process simulation.

## Project Overview

This project was developed as part of a university **Manufacturing Processes** group project.

The objective was to design and evaluate a complete forging process for a C45 steel mechanical component, starting from the nominal part geometry and progressing through forged-part design, tooling, process simulation, and optimization.

The project includes:

- Nominal component CAD modeling
- C45 material analysis
- Forged-part design
- Forging and machining allowances
- Flash design
- Billet dimensioning
- Die-block dimensioning
- Upper and lower die CAD design
- Forging assembly
- 2D QForm simulation
- 3D QForm simulation
- Stress and strain analysis
- Workpiece and tool temperature analysis
- Billet geometry optimization
- Lubrication analysis

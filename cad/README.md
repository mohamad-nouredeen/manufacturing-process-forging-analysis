# CAD Models

This folder contains the CAD models developed for the **C45 steel forging-process analysis**.

The models represent the main stages and tooling used in the manufacturing process, including the billet, forged component, upper and lower dies, forging assembly, upsetting stage, and trimming stage.

## Folder Structure

```text
cad/
├── solidworks/
│   ├── Forging_Assembly.SLDASM
│   ├── Billet.SLDPRT
│   ├── Forged_Part.SLDPRT
│   ├── Upper_Die.SLDPRT
│   ├── Lower_Die.SLDPRT
│   └── other tooling components
│
└── step/
    ├── Upsetting_Stage.STEP
    ├── Forging_Second_Stage.STEP
    └── Trimming_Stage.STEP
